# iOS Design System and UI Component Conventions

Money Vibe เลือก iOS Inset Grouped แบบ surface-first และ dark-mode-first เพราะช่วยให้ตัวเลขการเงินอ่านง่ายและให้ลำดับข้อมูลสม่ำเสมอ. ทางเลือก Material 3 แบบ default ทำให้ toggle, dropdown และ card แตกเป็นหลายรูปแบบ; gradient และ neumorphism เพิ่มความรกและลด contrast. กติกา UI ที่ใช้งานปัจจุบันอยู่ใน [design.md](../design.md) เพียงแห่งเดียว.
