# 06: รายจ่ายหรือรายรับสกุลต่างประเทศ

**What to build:** ตอนบันทึกรายจ่ายหรือรายรับ (เช่น รูดบัตร THB ในญี่ปุ่น) ผู้ใช้เปิด "ชำระเป็นสกุลต่างประเทศ" แล้วกรอกยอดสกุลต่างประเทศคู่กับยอดที่ตัดบัญชีได้ แอปเติมยอดที่ตัดบัญชีโดยประมาณจาก rate ตลาดไว้ให้ก่อน แล้วผู้ใช้แก้เป็นยอดจริงทีหลังได้ ยอดหลักยังเป็นสกุลของบัญชี ยอดคงเหลือ งบ และสถิติจึงไม่เปลี่ยน ดู spec ที่ `.scratch/foreign-currency/spec.md`

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] migration เพิ่มคอลัมน์ `foreign_amount` และ `foreign_currency` (nullable) ใน `transactions` พร้อม check constraint ว่าต้องว่างพร้อมกันหรือมีค่าพร้อมกัน แล้ว apply ด้วย `supabase db push`
- [ ] ฟอร์ม expense/income มีสวิตช์ "ชำระเป็นสกุลต่างประเทศ" ปิดไว้เป็นค่าเริ่มต้น เมื่อเปิดจะแสดงตัวเลือกสกุลและ widget กรอกสองสกุลจาก ticket 03
- [ ] เลือกสกุลเดียวกับบัญชีไม่ได้ และค่าเริ่มต้นเป็นสกุลต่างประเทศล่าสุดที่ใช้
- [ ] ยอดที่ตัดบัญชีเติมให้โดยประมาณจาก rate ตลาดปัจจุบัน และผู้ใช้แก้ได้ ไม่มีสถานะ pending
- [ ] รายการในลิสต์แสดง "¥3,000 → ฿702"
