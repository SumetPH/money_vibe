# 03: รายการแลกเงิน (`exchange`) ระหว่างบัญชีทั่วไป

**What to build:** ผู้ใช้เลือก type "แลกเงิน" เพื่อบันทึกการแลกเงินระหว่างสองบัญชีที่ไม่ใช่พอร์ต และคนละสกุลกัน กรอกได้สองในสามช่อง (จ่าย / ได้ / rate) แล้วแอปคำนวณช่องที่สามให้ รายการกระทบแค่ยอดคงเหลือของสองบัญชี และไม่นับเป็นรายรับรายจ่าย ดู spec ที่ `.scratch/foreign-currency/spec.md`

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] มี type `exchange` label "แลกเงิน" ไม่มี category และมีไอคอนกับสีของตัวเองตาม `docs/design.md`
- [ ] ฟอร์มแลกเงินแสดงเฉพาะบัญชีปลายทางที่สกุลต่างจากต้นทาง และยังไม่แสดงพอร์ตหุ้น
- [ ] widget กรอกสองสกุลมี 3 ช่อง (ยอดฝั่ง A / ยอดฝั่ง B / rate) สองช่องที่แก้ล่าสุดเป็นค่าที่ผู้ใช้กำหนด ช่องที่สามคำนวณและปัดตามทศนิยมของสกุล widget นี้ต้องนำไปใช้ซ้ำใน ticket 06 ได้
- [ ] rate แสดงเป็น "1 [สกุลต่างประเทศ] = x ฿" ถ้าไม่มีฝั่งไหนเป็น THB ใช้ "1 [ต้นทาง] = x [ปลายทาง]"
- [ ] DB เก็บแค่ `amount` และ `to_amount` ไม่เก็บ rate
- [ ] ยอดคงเหลือ: ต้นทาง −amount ปลายทาง +to_amount
- [ ] ไม่นับในรายรับรายจ่าย งบประมาณ cash flow และสถิติรายรับรายจ่าย
- [ ] รายการในลิสต์แสดงยอดทั้งสองฝั่งและ rate
- [ ] CSV export และ AI finance export รองรับ type `exchange`
- [ ] เพิ่มคำว่า "แลกเงิน" ใน `GLOSSARY.md`
- [ ] `dart format .` และ `tool/check_design.sh` ผ่าน
